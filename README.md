## ✨ Features

| | Feature | Description |
|---|---|---|
| 📱 | **Fully Responsive** | Mobile-first design that looks pixel-perfect on all screen sizes |
| 🎨 | **Cyber / Dark UI** | Sleek dark theme with Glassmorphism effects, gradient accents, and glowing elements |

## 🚀 How to Run Locally

Getting this project up and running on your machine is simple — no build tools or package managers required!

1. **Clone the repository**

   ```bash
   git clone https://github.com/inayat-engineer/Portfolio.git
   ```

2. **Navigate into the project folder**

   ```bash
   cd Portfolio
   ```

3. **Open in your browser**

   Simply open `index.html` in your favorite browser:

   ```bash
   # macOS
   open index.html

   # Windows
   start index.html

   # Linux
   xdg-open index.html
   ```

   Or just drag-and-drop `index.html` into any browser window. That's it — no servers, no installs! 🎉
